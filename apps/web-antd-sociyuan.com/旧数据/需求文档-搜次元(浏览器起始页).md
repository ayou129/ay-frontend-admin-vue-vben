
# 项目

## 项目介绍

本项目是一个 浏览器起始页，包含如下功能：

1. 搜索功能
2. 诸多插件
    - 时间插件
    - 搜索插件 (无法禁用，因为起始页搜索功能是必须的)
        - 支持点击或快捷键(Alt+1 2 3 4...) 切换 不同的搜索引擎 例如 baidu google ...
        - 点击搜索引擎左侧的图标(也是当前搜索引擎的图标) 最下方的 `搜索引擎偏好` 打开设置面板的 `搜索引擎偏好` 菜单
            - 支持设置默认的搜索引擎
            - 支持自定义搜索引擎(搜索框 placeholder 同步变更为对应引擎名称)
              - 支持点击测试 按钮，减少用户因填错地址导致的无效配置，这里目前先直接按照用户输入的网址和规则 跳转到 目标网址，让用户自行判断是否正确
    - 古诗词插件（每日动态显示古诗词内容）
    - 快捷启动栏
        - 类型
            - 点击后立即跳转(例如百度网盘icon需要立即跳转)
            - 弹窗(例如壁纸icon，需要弹窗选择壁纸；)
            - 主题切换，点击后弹出选择主题选择，从主题切换icon的上方弹出一个小菜单即可，主题会影响整个页面
            - 背景壁纸切换 点击后弹窗，选择壁纸，这里先用几个默认的壁纸临时提供选择
        - 可以根据tab进行分类展示

补充：

- 整个页面拖拽说明(拖拽会立即更新排序视觉，数据会请求变更，如果变更失败，则还原排序)
  - 拖拽区域限制
    - 插件区域 拖拽某插件进行排序 (搜索栏也是插件，所以可以拖拽和其他组件的排序)
    - 快捷启动栏 拖拽某图标进行排序
    - 设置面板 搜索引擎偏好 可以拖拽排序
  - 不支持支持跨区域拖拽 例如把 “古诗词插件” 拖到 “快捷启动栏” 里
  - 拖拽时增加磁吸 / 占位提示
  - 拖拽功能，不需要展示拖拽状态(例如不需要提示 拖拽插件卡片可调整顺序的字眼和图标) 和 拖拽图标，鼠标按住某个插件的时候 就可以打开拖拽了

## 样式说明

- 弹窗固定z-index 9999，其他的都正常，包括组件内的层级都是默认的，要保证弹窗显示在最上层
- 样式从最外层开始，除了定义了 文字字体、以及其他需要特别定义的全局样式之外，遵循的是 外层尽量不要约束太多，尽量让每个层级独立，最终完成合理的样式排版，并且要简单优雅，不要添加过于复杂的样式，参考苹果设计师的设计理念。

## 页面说明

- 首页
  - 插件列表
    - 根据排序显示所有已启用的插件
    - 提供的功能
      - 上下排序（支持所有插件的显示顺序，无论是否启用）
      - 置顶、置底(和上下排序不冲突，优先本设置)
        - 搜索栏插件也是可以调整顺序的
        - 置底的插件，不允许调整顺序，不准其他插件继续置底，不准他上方的插件下调顺序
        - 置顶的插件，不允许调整顺序，不准其他插件继续置顶，不准他下方的插件上调顺序
        - 当点击了置底或者指定后，应该将item移动到合适的位置
  - 启用 / 禁用控制（除搜索插件外，其他插件支持用户自主选择启用或禁用）
  - 这里单独说一下 快捷启动 插件的UI
    - 最上方是 居中的 分类切换，分类最右侧有 + 号 样式和分类一样，并且 分类过多时，可以通过 滚动条 以及鼠标滚轮进行切换
    - 如果某个 分类中 没有任何 快捷启动，则显示一个 提示语或者icon 并且 提示语或者icon 的高度 应该和 类似有一排快捷启动的UI 一样 包括高度和背景
    - 快捷启动的整体UI比较像Macox的快捷启动面板，相似度60%
    - 点击某个分类后，显示所有的 快捷启动item，里面不能再有添加的按钮
    - 当用户点击 + 号 添加快捷启动item时，首先会鉴权是否登录，如果已登录，会弹出一个 添加快捷启动item面板
- 右上角右侧-登录or打开profile按钮 可以打开设置面板，并且不需要遮罩(也就是说打开设置面板后，可以操作实际的插件)，且可以通过 Esc 关闭
  - 涉及到的面板
    - 登录 面板(这里不需要注册和重置密码，因为手机号和微信登录本身足够)
      - 登录方式
        - 手机号
        - 微信登录
    - 信息设置面板
      - 个人设置
        - 用户ID
        - 昵称
        - 手机号
        - 密码 提示星号
        - 注册时间
      - 账号安全
        - 暂无
- 右上角右侧-设置按钮 可以打开设置面板，并且不需要遮罩(也就是说打开设置面板后，可以操作实际的插件)，且可以通过 Esc 关闭
  - 插件管理
    - 启动/禁用 选择
    - 置顶/置底 选择
    - tips
      - 改变数据后，立即刷新首页效果，如果点击了保存，则保存数据并刷新首页，如果点击取消，则首页要回复到之前的状态
    - 目前已经有的插件
      - 时间插件
      - 古诗词插件
      - 快捷启动栏
  - 搜索引擎偏好
  - 主题设置
    - 背景图片
    - 插件间隔 上下间距
    - 插件间隔
    - 快捷启动background

## 开发步骤建议

第一阶段：基础框架搭建
修改 app.vue 为起始页布局
创建基础组件结构
实现搜索功能

第二阶段：插件系统
实现设置面板
实现时间插件
实现古诗词插件
实现快捷启动栏

第三阶段：交互功能
实现拖拽排序
实现主题切换

第四阶段：优化完善
性能优化
响应式适配
错误处理

第五阶段：额外需求

- 搜索组件 要记录搜索历史
  - 每个历史item 右侧提供删除按钮，并且提供批量删除 和 全部清空按钮 以及逻辑。
    - 支持选择模式，可以批量选择和删除历史记录项。
    - 如果 经过操作后没有任何历史记录，则tab需要自动关闭
  - 暂定最多保存20条数据(这里使用硬编码，后期使用服务器代理)，但是可以滚动查看
  - 按照时间倒序排列，最新的在最上面。
  - 历史列表的小tab面板 应该设定最大的高度和宽度，并且提供滚动条。
    - 宽度和高度要尽量小一些
    - 尽量不要增加额外的颜色，例如红色、绿色等，使用默认主题的颜色例如 灰色
- 登录逻辑
  - 涉及到的文件
    - api 文件
    - 状态管理文件
  - 涉及到 API
    - 微信登录注册/API
    - 手机号登录/注册API 携带验证码SMS
      - 获取验证码 API
