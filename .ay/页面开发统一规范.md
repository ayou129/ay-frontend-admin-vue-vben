
## 页面开发统一规范 ⭐

> 本章节总结了项目中所有管理页面的统一开发标准，新增页面必须遵循此规范

### 1. 页面布局架构

#### 方案 A：独立搜索表单 + 数据表格（推荐用于复杂搜索场景）

**适用场景：** 搜索字段多（3+ 字段）、需要与表格视觉分离

**布局结构：**
```
Page (auto-content-height)
  ├── 搜索表单 Panel
  │   └── 样式: mb-4 rounded-lg bg-white shadow
  │   └── 内容: <div class="p-4"><SearchForm /></div>
  │
  └── 数据表格 Panel
      └── 样式: rounded-lg bg-white p-6 shadow
      └── 内容: Tabs/Buttons + VxeGrid/Table
```

**示例页面：** 商品管理、商品分类

**代码模板：**
```vue
<template>
  <Page auto-content-height>
    <!-- 搜索表单 Panel -->
    <div class="mb-4 rounded-lg bg-white shadow">
      <div class="p-4">
        <SearchForm @search="handleSearch" @reset="handleReset" />
      </div>
    </div>

    <!-- 数据表格 Panel -->
    <div class="rounded-lg bg-white p-6 shadow">
      <!-- Tab切换（可选） -->
      <Tabs v-model:active-key="activeTab">
        <TabPane key="tab1" tab="标签1" />
      </Tabs>

      <!-- 操作按钮区域 -->
      <div class="mb-2 flex flex-wrap gap-2">
        <Button type="primary" @click="handleAdd">
          <Plus class="size-4" />
          添加
        </Button>
      </div>

      <!-- 表格 -->
      <Grid>
        <!-- 表格列定义 -->
      </Grid>
    </div>
  </Page>
</template>
```

#### 方案 B：VxeGrid 内置搜索表单（推荐用于简单搜索场景）

**适用场景：** 标准 CRUD 页面、搜索条件较少

**布局结构：**
```
Page (auto-content-height)
  └── VxeGrid
      ├── formOptions (内置搜索表单)
      ├── toolbarConfig.slots.buttons (操作按钮)
      └── columns (数据列)
```

**示例页面：** 用户管理、用户等级

**代码模板：**
```vue
<template>
  <Page auto-content-height>
    <VxeGrid>
      <template #toolbar-buttons>
        <Button type="primary" @click="handleCreate">
          新增
        </Button>
      </template>

      <!-- 自定义列插槽 -->
      <template #status="{ row }">
        <Tag>{{ row.status }}</Tag>
      </template>
    </VxeGrid>
  </Page>
</template>

<script setup lang="ts">
const [VxeGrid, gridApi] = useVbenVxeGrid({
  formOptions: {
    showCollapseButton: false,  // ⭐ 禁用展开/收起
    schema: [...],
    submitOnChange: true,
    showDefaultActions: true,
    submitButtonOptions: { show: false },
  },
  gridOptions: {
    columns: [...],
    toolbarConfig: {
      slots: { buttons: 'toolbar-buttons' },
    },
    proxyConfig: {
      ajax: { query: async () => {...} }
    },
  },
});
</script>
```

### 2. 搜索表单配置规范

#### 独立搜索表单（VbenForm）

```typescript
const [SearchForm, searchFormApi] = useVbenForm({
  // ⭐ 布局配置
  actionLayout: 'newLine',      // 按钮新起一行
  actionPosition: 'right',      // 按钮靠右对齐
  layout: 'horizontal',         // 水平布局
  compact: true,                // 紧凑间距

  // ⭐ 功能配置
  showDefaultActions: true,     // 显示默认按钮
  submitButtonOptions: {
    show: false,                // ❌ 隐藏搜索按钮（自动搜索）
  },
  // ❌ 不要自定义重置按钮文字，使用框架默认

  // ⭐ 自动搜索
  commonConfig: {
    disabledOnChangeListener: false,
    disabledOnInputListener: false,
    labelWidth: 80,
  },
  handleValuesChange: (values) => {
    emit('search', values);
  },
  handleReset: async () => {
    searchFormApi.resetForm();
    emit('reset');
  },

  // ⭐ 响应式列布局
  wrapperClass: 'grid-cols-1 md:grid-cols-2 lg:grid-cols-4',

  // 表单字段
  schema: [...],
});
```

**❌ 禁止配置：**
- `collapsed: true` - 不允许折叠
- `collapsedRows` - 不允许设置折叠行数
- `showCollapseButton: true` - 不允许显示展开/收起按钮
- `resetButtonOptions: { content: '重置' }` - 不允许自定义重置文字

#### VxeGrid 内置搜索表单

```typescript
const [VxeGrid] = useVbenVxeGrid({
  formOptions: {
    // ⭐ 必须明确禁用展开/收起
    showCollapseButton: false,
    
    schema: [...],
    
    submitOnChange: true,
    showDefaultActions: true,
    submitButtonOptions: { show: false },
    // ❌ 不要自定义 resetButtonOptions
  },
  gridOptions: {...},
});
```

### 3. 样式规范

#### 3.1 Page 容器

```vue
<Page auto-content-height>
  <!-- 内容 -->
</Page>
```

- ✅ 必须添加 `auto-content-height` 属性
- ✅ 让表格自动填充剩余高度

#### 3.2 搜索表单 Panel

```vue
<div class="mb-4 rounded-lg bg-white shadow">
  <div class="p-4">
    <SearchForm />
  </div>
</div>
```

- 外层：`mb-4 rounded-lg bg-white shadow`
- 内层：`p-4`

#### 3.3 数据表格 Panel

```vue
<div class="rounded-lg bg-white p-6 shadow">
  <!-- 表格内容 -->
</div>
```

- 样式：`rounded-lg bg-white p-6 shadow`
- 内边距比搜索表单大（p-6 vs p-4）

#### 3.4 按钮区域间距

```vue
<!-- Tab下方的按钮区域 -->
<div class="mb-2 flex flex-wrap gap-2">
  <Button type="primary">添加</Button>
  <Button>导出</Button>
</div>
```

- 与下方内容间距：`mb-2`
- 按钮之间间距：`gap-2`
- 支持换行：`flex-wrap`

#### 3.5 表格工具栏按钮

```vue
<!-- 在 VxeGrid 内 -->
<template #toolbar-buttons>
  <Button type="primary" @click="handleCreate">
    <Plus class="size-4" />  <!-- 图标尺寸 -->
    新增
  </Button>
</template>
```

```typescript
// 表格配置中添加
gridOptions: {
  toolbarConfig: {
    slots: {
      buttons: 'toolbar-buttons',
    },
  },
}
```

### 4. 表格配置规范

#### 4.1 表格高度自适应

```typescript
const gridOptions: VxeGridProps = {
  columns: [...],
  // ❌ 不要设置 height: 'auto'
  // ✅ 让表格自动适应 Page 容器高度
  keepSource: true,
  pagerConfig: {
    enabled: true,  // 有分页
  },
  // 或
  pagerConfig: {
    enabled: false,  // 无分页（如树形数据）
  },
};
```

#### 4.2 树形表格配置

```typescript
const gridOptions: VxeGridProps<Category> = {
  columns: [
    {
      field: 'name',
      title: '分类名称',
      treeNode: true,  // 树形节点
      align: 'left',
      minWidth: 200,
    },
    // ...
  ],
  // ❌ 不要设置 height
  keepSource: true,
  pagerConfig: {
    enabled: false,  // 树形数据通常不分页
  },
  treeConfig: {
    parentField: 'parent_id',
    rowField: 'id',
    transform: false,
  },
};
```

### 5. 未开发页面规范

对于功能暂未实现的页面，使用极简模板：

```vue
<script setup lang="ts">
// 页面逻辑
</script>

<template>
  <div class="p-4">
    <div class="rounded-lg bg-white p-6 shadow">
      <div class="text-center text-gray-500">
        <div class="mb-4 text-4xl">📊</div>
        <p>页面内容开发中...</p>
      </div>
    </div>
  </div>
</template>
```

**❌ 不要包含：**
- 页面标题 `<h1>`
- 页面描述 `<p>`
- 这些由路由菜单提供

### 6. 模态窗口/抽屉规范

#### 6.1 Modal 宽度配置

```vue
<template>
  <Page auto-content-height>
    <!-- 60% 宽度 Modal -->
    <SpuFormModal class="w-[60%]" :title="modalTitle">
      <SpuForm ref="formRef" :edit-data="editData" />
    </SpuFormModal>
  </Page>
</template>
```

- ✅ 使用 Tailwind 类：`class="w-[60%]"`
- ❌ 不要使用 `modalProps: { width: '60%' }`

#### 6.2 表单提交处理

```typescript
const [Modal, modalApi] = useVbenModal({
  onCancel() {
    modalApi.close();
  },
  onConfirm: async () => {
    try {
      await formRef.value?.submitForm();
      modalApi.close();
      gridApi.query();  // 刷新列表
    } catch {
      // 验证失败，不关闭弹窗
    }
  },
});
```

### 8. 快速检查清单 ✅

开发新页面时，请检查：

**布局：**
- [ ] Page 组件添加 `auto-content-height`
- [ ] 搜索 Panel：`mb-4 rounded-lg bg-white shadow` + `p-4`
- [ ] 表格 Panel：`rounded-lg bg-white p-6 shadow`
- [ ] 按钮区域：`mb-2 flex flex-wrap gap-2`

**搜索表单：**
- [ ] 独立表单使用 `actionLayout: 'newLine'` + `actionPosition: 'right'`
- [ ] VxeGrid 表单添加 `showCollapseButton: false`
- [ ] 隐藏搜索按钮：`submitButtonOptions: { show: false }`
- [ ] 不自定义重置按钮文字
- [ ] 启用自动搜索：`handleValuesChange`

**表格：**
- [ ] 不设置固定高度（移除 `height: 'auto'`）
- [ ] 操作按钮在工具栏：`toolbarConfig.slots.buttons`
- [ ] 图标尺寸统一：`class="size-4"`

**禁止项：**
- [ ] ❌ 不使用 `collapsed: true`
- [ ] ❌ 不使用 `showCollapseButton: true`（除了明确禁用）
- [ ] ❌ 不自定义 `resetButtonOptions.content`
- [ ] ❌ 未开发页面不显示标题和描述
